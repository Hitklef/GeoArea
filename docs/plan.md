# GeoArea — план роботи та стан

## Суть
Калькулятор площі полігона за координатами вершин (формула Гаусса) з виводом повної
«Відомості обчислення площі по координатам точок вершин» (стовпці 1–9 бланка
`docs/Відомість_обчислення_площі_по_координатам_чиста.doc`).

Формула: 2P = Σ Yn·(Xn−1 − Xn+1) = Σ Xn·(Yn+1 − Yn−1). Індекси циклічні.
Контроль: Σст.6 = 0, Σст.7 = 0, Σст.8 = Σст.9. P = |2P|/2, м² та га.

## Рішення (погоджено 2026-10-18)
- Стек: WPF, .NET 8, Windows; без сторонніх NuGet-пакетів у додатку.
- Вивід: повна відомість на екрані + площа в м² і га + індикатор контролю + попередження.
- Ввід: вручну в таблицю + вставка з буфера + відкриття .txt/.csv (кома/крапка, будь-який роздільник, номер точки необов'язковий).
- Експорт відомості: копіювання в буфер (текст + HTML), збереження у Word (.docx), друк.
- Дистрибуція: self-contained single-file exe; для передачі іншим людям — інсталятор Inno Setup (`installer/GeoArea.iss`, збирається `build-installer.cmd`, без прав адміністратора, українська мова, ярлик на робочому столі та в «Пуск», деінсталятор) + portable-zip; для розробника — `publish.cmd` (exe + ярлик).
- UI для людини, не сильної в комп'ютері: три пронумеровані кроки, підказка (ToolTip) на кожній кнопці, полі, заголовку та числі результату; короткий підпис під кожною кнопкою; постійна смуга з нагадуванням про підказки; жодної кнопки «Порахувати» — усе автоматично; повідомлення про помилки говорять, що саме зробити.

## Макет інтерфейсу
Інтерактивний макет погоджено 18.10.2026 (артефакт «GeoArea — макет інтерфейсу» на claude.ai,
копія джерела — `docs/ui-mockup/Main.dc.html`). WPF-вікно повторює його структуру:
крок 1 (таблиця координат + 4 кнопки + поле вставки) ліворуч, крок 2 (результат, контроль,
«як це рахується», налаштування) праворуч, крок 3 (відомість + кнопки експорту) на всю ширину,
рядок стану внизу.

## Що зробити далі (на машині з Visual Studio)
1. Відкрити `GeoArea.slnx`, зібрати (Ctrl+Shift+B), виправити можливі зауваження компілятора.
2. Запустити тести (Test Explorer) — усі мають бути зелені.
3. Запустити додаток, перевірити на `docs/sample-coordinates.txt` → **8 617,68 м² = 0,8618 га**.
4. Запустити `publish.cmd` → з'явиться `publish\GeoArea.exe` і ярлик на робочому столі.
5. Установити Inno Setup 6.3+ і запустити `build-installer.cmd` → у `dist\` з'являться `GeoArea-Setup-1.0.0.exe` та `GeoArea-1.0.0-portable.zip`. Перевірити інсталятор на іншому комп'ютері (або під іншим користувачем): установка без адміністратора, ярлик, запуск, видалення.

## Відкриті питання
- Шапка відомості (назва ділянки, виконавець, дата) — не додавалась; за потреби додати поля над таблицею і в експорт.
- Попередній перегляд перед друком — наразі одразу стандартний діалог друку.
