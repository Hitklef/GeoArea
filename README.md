# GeoArea — обчислення площі ділянки за координатами

Простий десктопний додаток для Windows, який за координатами вершин земельної ділянки
рахує її площу (формула Гаусса) і заповнює стандартну **«Відомість обчислення площі по
координатам точок вершин»** (стовпці 1–9 бланка). Розрахований на користувача, який не
сильний у роботі з комп'ютером: три пронумеровані кроки, підказка на кожній кнопці й полі,
автоматичний перерахунок без кнопки «Порахувати».

---

## Для користувача

### Встановлення і запуск
Запустіть файл **GeoArea-Setup-1.0.0.exe** і натискайте «Далі» — майстер установки українською
сам створить ярлик **GeoArea** на робочому столі та в меню «Пуск». Права адміністратора не потрібні,
.NET чи інші програми встановлювати не треба. Працює на Windows 10/11 (64-біт).
Видалити програму можна як звичайно: «Параметри → Програми» або через ярлик у меню «Пуск».

Якщо інсталятор запускати не можна (наприклад, обмеження на роботі) — є **portable-версія**
`GeoArea-1.0.0-portable.zip`: розпакуйте в будь-яку папку і двічі клацніть `GeoArea.exe`.

### Як порахувати площу
1. **Введіть координати вершин** у таблиці зліва — X та Y у метрах, по порядку обходу межі
   (за годинниковою стрілкою чи проти — байдуже). Десятковий роздільник — кома або крапка.
   Можна **вставити з буфера** список, скопійований з Excel/Word, або **відкрити файл** `.txt`/`.csv`.
2. **Результат** з'являється праворуч одразу, щойно введено 3 і більше точок: площа в м² і га
   та зелений напис «Контроль пройдено». Якщо результату немає — жовте повідомлення пояснює, що зробити.
3. **Відомість** унизу заповнюється автоматично. Її можна **скопіювати** (для вставки у Word/Excel),
   **зберегти у Word** (`.docx`) або **надрукувати**.

Докладна інструкція — кнопка **«Довідка»** у правому верхньому куті програми.

### Формат файлу з координатами
Кожна точка — з нового рядка; між X та Y — пробіл, табуляція, кома або крапка з комою.
Номер точки на початку рядка не обов'язковий. Приклад (`docs/sample-coordinates.txt`):

```
№	X	Y
1	5432,10	1234,56
2	5498,75	1301,20
3	5456,30	1389,45
4	5390,85	1322,80
```

Для цього прикладу програма має показати **P = 8 617,68 м² = 0,8618 га**.

## Як рахується (формула)

Формула Гаусса для площі многокутника за координатами вершин:

```
2P = Σ Yn · (Xn−1 − Xn+1) = Σ Xn · (Yn+1 − Yn−1)
```

Індекси циклічні: для першої точки «попередня» — остання, для останньої «наступна» — перша.

| Стовпець бланка | Зміст |
|---|---|
| 1 | № точки |
| 2, 3 | знак і значення X |
| 4, 5 | знак і значення Y |
| 6 | Xn−1 − Xn+1 |
| 7 | Yn+1 − Yn−1 |
| 8 | (ст. 6) · Yn |
| 9 | (ст. 7) · Xn |

Контроль: **Σ ст. 6 = 0**, **Σ ст. 7 = 0**, **Σ ст. 8 = Σ ст. 9 = 2P**. Площа P = |2P| / 2 (м²); 1 га = 10 000 м².
Знак суми залежить лише від напрямку обходу, тому береться модуль.

Додатково програма: не рахує двічі останню точку, якщо вона збігається з першою (замкнений контур; вимикається
в налаштуваннях); пропускає підряд повторені точки; попереджає про самоперетин межі та нульову площу.

## Для розробника

### Структура
```
GeoArea.slnx
├── src/GeoArea.Core            — розрахункове ядро (net8.0, без залежностей)
│   ├── AreaCalculator.cs       — формула Гаусса, контроль, самоперетин
│   ├── CoordinateParser.cs     — розбір тексту з координатами (буфер/файл)
│   └── Vertex / AreaRow / AreaResult / AreaOptions
├── src/GeoArea.App             — WPF-додаток (net8.0-windows)
│   ├── MainWindow.xaml(.cs)    — головне вікно (3 кроки), діалоги
│   ├── HelpWindow.xaml         — довідка
│   ├── ViewModels/             — MainViewModel, PointRowViewModel, WorksheetRowViewModel
│   ├── Services/               — WorksheetTable, ClipboardService, WordExporter, PrintService, TextFileService, NumberFormat
│   ├── Themes/AppStyles.xaml   — кольори, стилі кнопок/таблиць/підказок
│   └── Assets/app.ico
├── tests/GeoArea.Core.Tests    — xUnit-тести ядра і парсера
├── docs/                       — бланк відомості (.doc), макет UI, приклад координат, план
├── installer/GeoArea.iss       — сценарій інсталятора (Inno Setup)
├── build-installer.cmd         — збірка інсталятора + portable-архіву в dist\
├── publish.cmd                 — збірка одним exe + ярлик на робочому столі (для себе / розробника)
└── scripts/create-shortcut.ps1
```

Ядро не залежить від UI, тому його можна використати повторно (наприклад, у вебверсії).
Усі три виводи відомості (буфер, Word, друк) будуються з одного `WorksheetTable`, щоб бути однаковими.
Word-файл формується вручну за стандартом Office Open XML через `System.IO.Packaging` — без сторонніх пакетів.

### Вимоги
- Visual Studio 2022/2026 з навантаженням «.NET desktop development» **або** .NET 8 SDK (чи новіший).
- Сторонніх NuGet-пакетів у додатку немає; тести використовують xUnit.

### Збірка та запуск
```
dotnet build GeoArea.slnx
dotnet test  GeoArea.slnx
dotnet run --project src/GeoArea.App
```

### Інсталятор для передачі іншим людям
Один раз установіть безкоштовний [Inno Setup 6.3+](https://jrsoftware.org/isdl.php), потім запускайте
`build-installer.cmd`. Скрипт:
1. збирає `publish\GeoArea.exe` — self-contained, single-file, win-x64 (у користувача не має бути встановлений .NET);
2. пакує `dist\GeoArea-1.0.0-portable.zip` (exe + інструкція + приклад);
3. компілює `dist\GeoArea-Setup-1.0.0.exe` за сценарієм `installer/GeoArea.iss`.

Інсталятор: майстер українською (є й англійська), установка в папку користувача без прав адміністратора
(або в Program Files, якщо запущено від адміністратора), ярлик на робочому столі (увімкнено за замовчуванням)
і в меню «Пуск», деінсталятор, коректне оновлення поверх старої версії (той самий `AppId`), закриття
запущеної програми перед оновленням. Передавати людям достатньо один файл `GeoArea-Setup-1.0.0.exe`.

**Нова версія:** змініть номер у трьох місцях — `<Version>` у `src/GeoArea.App/GeoArea.App.csproj`,
`MyAppVersion` в `installer/GeoArea.iss`, `VERSION` у `build-installer.cmd` — і запустіть збірку ще раз.
`AppId` в `.iss` не чіпайте, інакше оновлення встановиться поруч зі старою версією.

### Швидка збірка для себе (без інсталятора)
`publish.cmd` збирає той самий `publish\GeoArea.exe` і одразу створює ярлик на робочому столі поточного
користувача (через `scripts/create-shortcut.ps1`). Зручно для розробника; іншим людям передавайте інсталятор.

### Налаштування в коді
- Кількість знаків у відомості: `MainViewModel.Decimals` (2/3/4, перемикається в UI).
- Допуск контролю: `AreaOptions.Tolerance` (масштабується під величину сум у `AreaCalculator`).
- Кольори й розміри: `Themes/AppStyles.xaml`.
